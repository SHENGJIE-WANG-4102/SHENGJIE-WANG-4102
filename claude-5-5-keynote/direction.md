### Apple 发布会

- 双色标题：第一行写结论（黑），第二行写补充（灰）
- 对比图只给新品上色，旧款和竞品一律灰
- 大数字配小单位，数据出处写成小字脚注
- 一页只讲一件事，留白多到有点奢侈
- 落版只放产品名和上市时间

### 不拿的

Apple 的产品渲染、玻璃质感、光扫过文字。这些要么需要真实 3D 素材，要么一做就成了“AI 味”的光效。

## 3. Direction

**配色**

| 用途 | 色值 |
|---|---|
| 底 | `#f5f5f2` 暖白 |
| 字和黑色 UI | `#0e0e10` |
| 次要文字 | `#8b8b87` |
| 双色标题第二行 | `#a3a39e` |
| 灰色柱子 | `#d4d4cf` / `#e2e2dd` |
| Opus | `#ff5a1f` |
| Sonnet | `#2f5bff` |
| Haiku | `#cdf24f`，只在黑底上用；暖白底上用空心圈 `#a9c92a` |

**规则：一个镜头只出现一个强调色**，也就是当前章节那个模型的颜色。唯一的例外是落版，三个点同时出现。

**字体**

- 拉丁字母和数字：Geist 700，字距 −0.03 到 −0.055em
- 中文：Noto Sans SC 700
- 脚注和模型 ID：Geist Mono
- 屏幕上不出现句号

**版式**

- 左右边距 160px
- 章节标签固定在左上角（y = 136）
- 脚注固定在底部 72px 处
- 标题字号：104–112px；大数字：248px

**运动语言**：只用 6 种变法，都以拍为单位。

| 变法 | 用在哪 | 时长 |
|---|---|---|
| 遮罩升起：文字从一条看不见的线下面升上来 | 所有标题 | 1–1.5 拍，ease-out-expo |
| 弹簧弹出：从 0 弹到 1，回弹约 12% | 圆点、徽章 | 1 拍 |
| 柱子画出：从左往右长 | 跑分柱 | 每根 1 拍，错开半拍 |
| 整页推走 | Opus → Sonnet | 1 拍 |
| 色块铺满再收缩：圆形从一个点涨满全屏，再收缩到下一场的某个点 | 章节切换 | 涨 1 拍，收 1 拍 |
| 变形：同一个物体变成下一场的东西 | 三个点 → 小数点 → 标签点 | 2–3 拍 |

**镜头**：不推不摇，画面本身不动，只有里面的东西在动。

**禁用**

- 淡入淡出、模糊转场、硬切
- 光晕、粒子、镜头光晕、冲击波圈、RGB 分离、镜头抖动、霓虹、装饰性渐变、3D
- 角落 HUD 标签（上一部有，这次去掉）
- 假窗口装饰（比如红黄绿三个按钮）
- emoji、句号
- 随机运动
- 一个镜头里出现两个强调色

## 5. Build

- 和 `../claude-5-5` 用同一套方法：`seek(t)` 是纯函数，Playwright 逐帧截图，ffmpeg 合成
- zero 的片子是 60fps，这次也用 60fps：40 秒是 2400 帧，分 4 段并行渲染
- 弹簧用解析式（`1 − e^(−6.5t)·cos(9.5t)`），任意一帧都能直接算出来，不靠 CSS transition
- `frames.html` 里的每个场景函数，build 阶段直接拿来改成按时间驱动

## 6. Gotchas

| 风险 | 对策 |
|---|---|
| Geist 没有中文，中文会回落到 Noto Sans SC，中英混排时基线和字重对不齐 | 中英分开排，数字一律用 Geist；每个关键帧都检查一遍 |
| 遮罩升起时被裁掉字的下伸部分 | 遮罩加 0.1em 底部余量；大标题的遮罩高度按实测的字形盒子算（KF2 就是这样修好的：小数点之前偏低 40px） |
| 铺满用的圆不够大，角落露出来 | 半径取圆心到最远角的距离再加 4px |
| 偷懒用了淡入淡出 | 渲染后抽帧检查：任何画面元素不允许出现 0 < 不透明度 < 1 的中间状态 |
| 柱子上的数字跟不上柱子的头 | 数字挂在柱子末端，跟着同一个变换走 |
| 数字跳动时宽度抖 | 开 `tnum` 等宽数字 |
| 荧光绿放在暖白底上看不清 | 荧光绿只用在黑底上；落版的 Haiku 改成深一点的绿色空心圈 |
| 字太长溢出 | 中文标题一行最多 11 个字，英文副标题最多 60 个字符 |
| 数据出错 | 只用发布页原文里的数字；Haiku 5.5 不写 ID、价格、跑分 |
| 被误认成官方作品 | 不用 logo，落版写非官方声明 |
| 动作太快，单帧发糊 | 60fps 下，每帧位移超过 80px 的动作要么放慢，要么做子帧采样模拟动态模糊 |

## 8. QC

- 关键帧确认后，先对 41 个转场中间帧逐张检查
- 修掉两个问题：
  - 字体还没加载完就测量了标题，小数点跑偏，“5.5” 看起来像 “55”；现在先显式加载字体再测量
  - 柱子收回时数字会倒着往回数；现在收回时数字停在终值
- 成片抽检：每 2 秒抽一帧拼成联系表；四段并行渲染的接缝处前后各取一帧，画面都连续
- 全片没有用到任何不透明度变化，所以不可能出现淡入淡出
- 配乐按小节检查响度（dBFS）：

  | 段落 | 响度 |
  |---|---|
  | 开场 | −18.5 |
  | 标题 | −15.5 |
  | Opus | −13.3 |
  | Sonnet | −13.9 |
  | breakdown | −18.3 |
  | 最后副歌 | −12.9 |
  | 落版 | −15.4 |

  橙色铺满（8 秒）、黑色收缩回三个点（32 秒）、最后一个和弦（36 秒）这三处，起音前后的电平都有明显跳升，确认音画对拍。

- 分 4 段并行渲染，每段约 95 秒，再无损拼接
